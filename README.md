# CodeGuard

**Smart Project Risk & Quality Management Platform**

CodeGuard is a full-stack web application for managing project tasks, bugs, and project risk.

## Features

- User Registration and Login
- Task Management
- Bug Tracking
- Project Risk Analysis
- Dashboard Statistics
- Project Health Monitoring
- SQLite Database
- Flask Backend
- Responsive Frontend

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## Project Structure

CodeGuard/
├── backend/
│   ├── app.py
│   └── database.py
├── index.html
├── style.css
└── script.js

## How It Works

1. Register and log in.
2. Add and manage project tasks.
3. Add bugs with severity levels.
4. Analyze project risk.
5. View project statistics and project health.
